# BetawiBoys

**Modern Fashion. Local Culture. Authentic Identity.**

BetawiBoys adalah platform penjualan fashion yang mengangkat identitas dan budaya Betawi melalui produk pakaian, layanan produksi pakaian custom, serta konten edukasi budaya lokal.

Proyek ini dikembangkan menggunakan Laravel dan React dengan fokus pada desain modern, pengalaman pengguna, serta pengembangan sistem yang terstruktur.

## Tentang Proyek

BetawiBoys menggabungkan kebutuhan bisnis fashion dengan upaya memperkenalkan budaya Betawi melalui platform digital.

Platform ini memiliki tiga bagian utama:

- **BetawiBoys Store** — platform penjualan produk fashion bertema Betawi.
- **One Production** — layanan produksi pakaian custom dan seragam.
- **Betawi Culture** — konten berita, informasi, dan edukasi mengenai budaya Betawi.

## Fitur Utama

### BetawiBoys Store

- Halaman utama dengan identitas visual brand.
- Tampilan katalog produk fashion.
- Informasi dan gambar produk.
- Pengembangan pengalaman belanja online.

### One Production

- Halaman layanan produksi pakaian custom.
- Informasi produksi seragam dan pakaian.
- Fasilitas pengajuan permintaan produksi.
- Pengembangan sistem pemesanan custom.

### Konten Budaya Betawi

- Informasi mengenai budaya Betawi.
- Artikel dan berita seputar budaya lokal.
- Pengembangan konten edukasi digital.

*Catatan: Daftar fitur mencakup ruang lingkup pengembangan. Implementasi setiap fitur mengikuti kondisi kode aplikasi saat ini.*
